# Public pages: prerendered shell, content fetched at runtime

The frontend stays a React + Vite app, built with React Router in framework mode (`ssr: false` plus a `prerender` list, so the output is static files). Public pages are prerendered at build time per Locale so crawlers get real HTML, titles, meta descriptions and `hreflang` tags, then hydrate and fetch Editable Texts, Gallery Images and Opening Hours from the API. This means an Owner's edit shows to Visitors immediately without a rebuild, while search engines see the prerendered fallback text until the next deploy. Next.js SSR was rejected because it changes the stack and needs a Node server in production; a plain SPA was rejected because a barbershop depends on local search.
